# Molecular Heart | 강훈구 연구실

전주대학교 과학교육과 강훈구 연구실 홈페이지입니다. 연구실 구성원, 연구 분야, 논문, 연구실 사진을 소개합니다. 논문 메뉴에서는 제목, 저자, 저널, 연도로 연구실 논문을 검색할 수 있습니다.

## 홈페이지 수정 및 배포

1. 작업 폴더의 `hungu_kang_lab_homepage_molecular_heart_final_v2.html`을 브라우저에서 열어 수정 내용을 확인합니다.
2. **추억** 메뉴에서 공개할 사진을 추가한 뒤 **사진 반영 index.html 저장**을 눌러 공개용 파일을 저장합니다.
3. 공개용 `index.html`과 이 `README.md`를 GitHub 저장소의 최상위에 올립니다.
4. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **`main`**, **`/ (root)`**를 선택하고 저장합니다.

배포가 완료되면 **Settings → Pages**의 **Visit site**에서 홈페이지를 열 수 있습니다. 홈페이지를 업데이트하려면 새 공개용 `index.html`을 같은 위치에 올려 커밋합니다.
